# WebLib

The public-facing site for WebLib, a web development studio presenting its services, selected work, and learning resources. The site is available in English and Arabic.

**Live site:** [web-lib-one.vercel.app](https://web-lib-one.vercel.app/en)

## What’s included

- English and Arabic content with language switching
- Responsive pages for services, portfolio projects, tutorials, downloads, and contact
- Light and dark themes
- Motion-enhanced interface components

## Built with

Next.js 15 · React 18 · TypeScript · Tailwind CSS · next-intl · Framer Motion

## Run locally

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)

To create a production build, run `npm run build`.
